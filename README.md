# Project Information
Name: YourFit
Short Description: YourFit is a platform that offers different fitness programs that align to the goals of the customers.
Programming languages used: HTML, CSS, JS
Frameworks used: Next.js, React, Tailwind CSS

# Software / Technology Requirements
-Node.js - version 20.9 or later
-npm - installed with Node.js
-A web browsers

# Instructions for Running the Application
1. Install Node.js if it's not already installed
2. Download YourFit project folder
3. Open a terminal inside the project folder
4. Install the required dependencies with "npm install"
5. Start the server with "npm run dev"
6. Open a web browser and navigate to "https://localhost:3000
